## 4. 技术选型速查矩阵

按**准确率优先级**和**成本约束**双维度推荐：

```
预算充足，追求最高准确率：
  推理任务 → ToT (BFS) 或 Self-Consistency
  分类任务 → Claude + Few-Shot + Prefill
  QA任务   → RAG + 引用验证 + temperature=0

预算中等，平衡准确率和成本：
  推理任务 → CoT + Few-Shot
  分类任务 → Few-Shot + XML结构
  QA任务   → 先找证据后回答 + 退出选项

预算紧张，追求性价比：
  推理任务 → CoT (GPT-4o-mini) 或 DeepSeek-R1
  分类任务 → Few-Shot (开源模型)
  QA任务   → 引用要求 + 退出选项 (开源模型)
```

## 5. 常见错误与修正效果

| 错误类型 | 常见原因 | 修正方法 | 修正后效果 |
|----------|----------|----------|-----------|
| JSON格式错误 | 无格式约束 | 加JSON schema + prefill | 格式正确率 60%→95%+ |
| 幻觉编造 | 无grounding约束 | 加"仅使用提供的信息"+退出选项 | 幻觉率 18%→3% |
| 输出不一致 | 无few-shot锚定 | 加3-5个示例 | 一致性 65%→90%+ |
| 角色过于刻板 | 角色定义太强 | 弱化为"专业视角" | 可用性显著提升 |
| 长文本遗漏 | 无分步指令 | 加XML标签分块+逐步处理 | 完整性 70%→92% |
